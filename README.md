# P3 - Konsep Dasar React

## Aplikasi Profil Mahasiswa
Tugas ini memandu mahasiswa membuat aplikasi React sederhana dengan pendekatan component-based development. Aplikasi yang dibangun menampilkan profil mahasiswa melalui beberapa komponen yang memiliki tanggung jawab jelas.
> Hasil akhir: Mahasiswa mampu membuat aplikasi React sederhana menggunakan component, JSX, props, children, dan event handling.


## Tujuan Pembelajaran
Setelah menyelesaikan praktikum ini, mahasiswa diharapkan mampu:
1.	Membuat proyek React menggunakan Vite.
2.	Menjelaskan fungsi component dalam aplikasi React.
3.	Menulis UI menggunakan JSX.
4.	Memecah aplikasi menjadi `App`, `Header`, `Profile`, `Biodata`, dan `Footer`.
5.	Mengirim data dari component induk ke component anak menggunakan props.
6.	Menggunakan `children` untuk membuat component pembungkus yang fleksibel.
7.	Menampilkan data secara kondisional menggunakan JSX.
8.	Menangani interaksi pengguna dengan event `onClick`.
